# 문제 재료 스크래퍼 + 출제 파이프라인

**12:55 OX 퀴즈**의 문제 공급 도구. 버튼 한 번으로 ① 최근 N일(기본 8일)의 그룹웨어 공지·뉴스와
지식재산 뉴스를 수집하고 → ② 바로 이어서 OX 문항·서든데스 문항을 생성하고 → ③ 화면에서 검수한
문항만 게임(`KIPlay_OX/data/questions.json`)에 반영한다.

> PRD 11.1의 **문제 공급 파이프라인** 구현이다. 할루시네이션 차단 원칙 그대로 —
> **evidence(근거 원문 문장)가 수집된 원문에 실제로 존재하지 않는 문항은 자동 폐기**된다.

프로젝트 본체와 같은 원칙: **의존성 0, Node 내장 모듈만.** `npm install` 필요 없음.
(Claude API 호출도 내장 https로 직접 한다.)

## 문항 생성 엔진 (하이브리드)

| 엔진 | 조건 | 특징 |
|---|---|---|
| **Claude API** (`claude-opus-5`) | API 키 입력 시 (UI 입력 또는 `ANTHROPIC_API_KEY`) | 자연스러운 문항, 그럴듯한 X 문항(사실 변형), 난이도 배분. 회당 수백 원 수준 |
| **규칙 기반** (폴백) | 키 없음 / API 실패 시 | 원문 문장 그대로 O 문항, 숫자 치환 X 문항, 빈칸 서든데스. 오프라인·무료 |

두 엔진 모두 동일한 검증을 통과해야 한다: evidence 원문 대조(글자 단위), answer O/X,
난이도·카테고리 enum, 서든데스 숫자의 원문 존재 여부. 개인 신상 공지(발령·부고·경조 등)는
출제 재료에서 자동 제외된다.

## 실행 — 버튼 UI (권장)

```bash
node server.js
```

브라우저에서 <http://127.0.0.1:8899/> 를 연다. 화면에서:

1. 수집 기간(일)을 정한다. 기본 8일.
2. 그룹웨어까지 포함하려면 체크 후 **본인의 그룹웨어 ID/비밀번호**를 입력한다.
3. (선택) **Anthropic API 키**를 입력하면 Claude가 문항을 생성한다. 비우면 규칙 기반.
4. **수집 + 퀴즈 생성 시작** 버튼을 누른다. 진행 로그가 흐르고, 끝나면 소스별 건수와 생성 문항이 표시된다.
5. **검수 패널**에서 문항 내용을 확인하고, 게임에 넣을 것만 체크한 뒤 **게임에 반영**을 누른다.
   - 기존 `questions.json`은 `questions.backup.<일시>.json`으로 자동 백업된다.
   - 이 도구는 이제 게임 repo 안(`tools/quizgen/`)에 산다. 기본 반영 경로는
     `../../data/questions.json`이고, 다르면 `GAME_QUESTIONS`로 지정한다.
   - 반영하면 게임 서버(`GAME_URL`, 기본 127.0.0.1:12055)에 **자동으로 리로드를 요청**한다.
     서버가 꺼져 있으면 다음에 켤 때 새 은행을 읽으므로 그냥 두면 된다.

> 서버는 **127.0.0.1(로컬 전용)**에만 바인딩된다. 입력한 비밀번호는 이 PC의 로컬 서버가
> 로그인에만 쓰고, **파일이나 로그에 저장하지 않는다.** 네트워크로 나가는 곳은 그룹웨어 로그인
> 요청뿐이다.

포트를 바꾸려면 `SCRAPER_PORT=9000 node server.js`.

## 실행 — 명령줄 (헤드리스)

```bash
node run.js 8
```

뉴스 3종만 수집한다. 그룹웨어까지 포함하려면 환경변수로 로그인 정보를 준다(파일에 남기지 말 것):

```bash
GW_ID=사번 GW_PW=비밀번호 node run.js 8
```

## 결과물

`scraper/output/` 에 실행 시각(`YYYYMMDD`) 기준으로 세 파일이 생긴다.

| 파일 | 용도 |
|---|---|
| `material_<날짜>.json` | 구조화 원문 (소스·제목·날짜·본문·첨부·근거문장) |
| `material_<날짜>.md` | 사람이 읽는 정리본 |
| `questions_candidates_<날짜>.json` | 문항 후보 골격 (근거 문장만 채워진 상태) |
| `questions_generated_<날짜>.json` | **생성 완료된 OX·서든데스 문항** (검수 전 상태 + 검증 탈락 목록 포함) |

### 문제 후보 스키마

```json
{
  "id": "q-20260820-kipo-01",
  "text": "",            // AI 단계가 생성
  "answer": "",           // AI 단계가 생성
  "difficulty": "",       // AI 단계가 라벨링
  "category": "ip-policy",
  "source": { "title": "...", "url": "https://..." },
  "evidence": "근거가 되는 본문 한 문장",
  "_material": { "sourceName": "...", "date": "...", "evidence": [...], "bodyExcerpt": "..." },
  "_needsGeneration": true
}
```

`evidence`(근거 원문 문장)가 없는 항목은 후보에서 제외된다 — PRD의 할루시네이션 차단 원칙 그대로.
`category` 값: `company-notice`(공지) · `company-news`(뉴스&행사) · `ip-policy`(지식재산처) ·
`kipi-news`(한국특허정보원) · `ip-news`(특허뉴스).

> `output/`에는 그룹웨어 내부 공지 본문이 담길 수 있다. 외부로 공유하기 전에 개인정보·대외비를 확인할 것.

## 구조

```
scraper/
  server.js            버튼 UI 로컬 서버 (127.0.0.1, SSE 진행 로그)
  run.js               헤드리스 CLI
  core.js              전체 소스 오케스트레이션 + 출력
  lib/
    http.js            HTTP 클라이언트 (쿠키·리다이렉트·gzip·인코딩)
    html.js            태그 제거·엔티티 디코드·id 추출·문장 분리
    dates.js           날짜 파싱과 최근 N일 판정 (달력일 기준)
    output.js          JSON·MD·문항 파일 생성
    quizgen.js         OX 문항 생성 (Claude API + 규칙 기반 폴백, 원문 대조 검증)
  sources/
    groupware.js       gw.kipi.or.kr 로그인 + 공지/뉴스행사
    kipo.js            지식재산처 보도자료
    kipi.js            한국특허정보원 KIPI소식
    patentnews.js      특허뉴스
  public/index.html    버튼 화면
  output/              결과물 (자동 생성)
```

## 알아둘 것

- **사내망 TLS 검사.** 이 환경은 사내 프록시가 TLS를 가로채 자체 서명 루트 인증서를 물린다.
  Node 기본 신뢰 저장소가 이를 모르므로, 기본값으로 인증서 검증을 건너뛴다(알려진 공개/사내
  엔드포인트 대상). 엄격 검증을 켜려면 `SCRAPER_STRICT_TLS=1` 을 주고, 사내 루트 CA를
  `NODE_EXTRA_CA_CERTS`로 지정한다.
- **그룹웨어 로그인 실패 시** ID/비밀번호를 확인한다. 로그인은 비밀번호를 SHA256으로 해시해
  ASP.NET 폼(`index1.aspx`)에 보내는 실제 로그인 흐름을 그대로 재현한다.
- **한국특허정보원 KIPI소식은 갱신이 드물다.** 최근 8일 안에 새 글이 없으면 0건이 정상이다.
- 페이지네이션은 각 소스에서 최근 글이 창(window)을 벗어나면 자동으로 멈춘다.
